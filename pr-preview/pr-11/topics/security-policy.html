SECURITY.md#

Does the repository say how to report a vulnerability?

It applies to 151 repositories: 94 done, 2 partial and 55 missing. 287 are not applicable and left out of the tables.

We look for a SECURITY.md where GitHub does: in the repository’s .github folder, root and docs folder, then in the organization’s .github repository. A repository needs one if it ships a package or a container image. When the repository and its organization both have one, we compare the emails they list.

  • done It has a SECURITY.md, its own or its organization’s.

  • partial Its own SECURITY.md lists other emails than its organization’s, so reports may go to the wrong place.

  • missing It ships a package or an image and has no SECURITY.md, not even its organization’s.

  • n/a It ships no package or image.
