# zizmor

Does the repository check its GitHub workflows with zizmor\?

It applies to 284 repositories: 23 done, 3 partial and 258 missing. 154 are not applicable and left out of the tables.

We look for zizmor in the repository\'s workflows and action files \(its GitHub Action or a command\) and in its pre\-commit hooks\. Comments are ignored\, so a note like \"zizmor\: ignore\" does not count\. A pre\-commit hook counts as running in CI when a workflow runs pre\-commit or the pre\-commit config has a \"ci\" section\, which sets up pre\-commit\.ci\.

- [done]{.status .status-done} zizmor runs in CI\.
- [partial]{.status .status-partial} zizmor is set up\, but nothing shows that CI runs it\.
- [missing]{.status .status-missing} The repository has workflows and no sign of zizmor\.
- [n\/a]{.status .status-na} The repository has no GitHub workflows to check\.
